Add Light support:
- A new button in the menu lets you show floating icons at the position of each light in your cell
- They can be selected, moved and duplicated like any other object
- While moving a light: The Right thumbsticks X-Axis changes the lights radius

Grid Mode: 
- Bugfixes: Objects now align properly to the grid
- The 'Y' Key now toggles Grid Mode on & off 

3DUI Update:
- VR Editor now required 3DUI 0.10
- Requires 3DUI 0.10.4: element scale means the same thing at creation and at
  runtime there now, so the object handles and the sphere-select radius are sized
  against the corrected scale and look exactly as before
